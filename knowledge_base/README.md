# 陕西准铁饭碗试题知识库

> 收录陕西省内国企、学校、医院等"准铁饭碗"单位的笔试/面试真题及模拟题

## 内容概览

- **25个单位** × **2份模拟题** = 50+ 个模拟题文件
- **11份历年真题**（2024年回忆版）
- **AI生成模拟题**（使用mmx-cli）

## 单位分类

| 分类 | 单位数 |
|------|--------|
| 水务集团 | 2 |
| 电力能源 | 4 |
| 城投平台 | 3 |
| 学校 | 7 |
| 医院 | 2 |
| 银行金融 | 2 |
| 其他国企 | 5 |
| **总计** | **25** |

## 文件结构

```
knowledge_base/
├── 模拟题/          # AI生成模拟题
│   ├── 【模拟题】+ 单位名称  # 笔试题
│   └── 【面试题】+ 单位名称  # 面试题
├── 真题/            # 历年真题
└── 知识库总索引.md
```

## 工具支持

- [mmx-cli](https://github.com/MiniMax-MMX/mmx-cli) - AI生成模拟题
- TikOmni - 微信公众号监控
